# Roadmap

This roadmap reflects real, current work — no speculative feature list and no dates that haven't been committed to. See [Project Status](project-status.md) for what is verified today.

## Available Now

- Working Arduino firmware — camera capture/streaming, Wi-Fi, IMU, secure element, I/O expander, microphone, microSD, RGB/1W LED control, serial command interface
- Public hardware documentation — hardware overview, pinout, camera guide, firmware guide, flashing guide
- Extracted example sketches for camera capture, Wi-Fi streaming, and LED control
- Approved schematic (PDF) and a parts-level BOM
- Real hardware photos
- Firmware (MIT) and hardware/documentation (CERN-OHL-P v2) licensing

## In Progress

- Recorded hardware demo (boot → camera → stream) — see [Demo Recording Checklist](DEMO_RECORDING_CHECKLIST.md)
- Crowd Supply application preparation

## Planned

- Additional firmware examples as they're extracted and verified from working code
- Expanded troubleshooting and FAQ content as real user issues come in
- Community example submissions via pull request (see [CONTRIBUTING.md](../CONTRIBUTING.md))

This roadmap intentionally does not include unannounced hardware features, on-device AI capabilities, or fixed ship dates. If something isn't listed here, it hasn't been committed to.
