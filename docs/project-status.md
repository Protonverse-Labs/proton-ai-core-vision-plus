# Project Status

This page states plainly what has and has not been verified, so nobody has to guess. It reflects the project owner's own current status record.

## Current Stage

**Working hardware prototype.**

## Verified

- Physical Proton AI Core Vision+ boards have been produced
- Hardware has been tested physically
- ESP32-S3-based
- USB-C works
- Wi-Fi works
- Current firmware is operational
- Camera (OV5640) is operational, including capture and streaming
- Firmware can be flashed successfully

## Not Yet Verified / Not Yet Claimed

The following have intentionally **not** been measured or are not being claimed until they are:

- On-device AI acceleration
- Specific frame-rate (FPS) figures at any resolution
- Current consumption figures
- Operating temperature range
- Industrial certification
- CE / FCC certification

If you see any of the above stated as a fact elsewhere in this repository, please [open an issue](../.github/ISSUE_TEMPLATE/) — it should not be there without measured data behind it.

## Production

- **Mass production:** not yet launched
- **Crowd Supply:** application in preparation

## Documentation

Documentation is under active development alongside the hardware and firmware. If something in `docs/` looks wrong, incomplete, or unverifiable, please report it — see [CONTRIBUTING.md](../CONTRIBUTING.md).
